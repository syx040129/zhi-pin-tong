# 企业搜索实现与验证

## 功能

- 首页支持“职位 / 公司”切换，职位关键词匹配岗位名、类型、公司名、技能。
- 顶部及移动导航新增“找公司”，页面地址为 `/companies`。
- 企业列表支持名称、行业、规模筛选和分页，默认仅展示有在线岗位的正常企业；可勾选包含暂无在招职位的企业。
- 企业详情 `/companies/:id` 展示简介、地址、有效的 HTTP/HTTPS 官网链接及分页在招职位。
- 职位列表和职位详情中的企业名称可进入企业主页。主页的“筛选企业职位”携带 `companyId`，继续筛选或翻页时保留该条件。
- 筛选和分页写入 URL，刷新及浏览器返回后恢复；加载失败与无结果分别展示，并提供重试。

## 接口与数据

| 接口 | 用途 |
| --- | --- |
| `GET /api/companies` | 名称、行业、规模、是否包含暂无招聘企业、分页 |
| `GET /api/companies/filters` | 正常企业的行业、规模选项 |
| `GET /api/companies/{id}` | 公开企业详情及在线岗位数 |
| `GET /api/jobs/page` | 新增企业 ID 筛选，关键词扩展匹配企业名称和技能 |

公开列表及详情采用独立的 `PublicCompanyVO`，不返回绑定用户 ID、用户名、手机号或后台状态。企业列表和公开岗位检索均排除禁用、已删除企业；岗位数只统计未删除的在线岗位。列表通过一次分组聚合获取本页所有企业的在线岗位数，无逐企业计数查询。

关键词子查询采用参数绑定和 `EXISTS`，多项技能同时命中时岗位只返回一次。职位排序增加 ID 作为第二排序条件，避免同一发布时间或同一薪资的岗位跨页重复、遗漏。新增筛选参数不需要修改数据库表结构。

完整字段与参数见 [接口说明](接口说明.md)。

## 验证方式

在 `frontend` 目录执行 `npm run build`，包含 TypeScript 检查及生产构建。在 `backend` 目录执行 `mvn test`、`mvn package -DskipTests`。

端到端脚本为 `backend/scripts/verify-company-search.cjs`。它需要本机 MySQL CLI、Java、Node、Playwright 和 Chrome；可通过 `MYSQL_CLIENT` 指定 MySQL CLI 路径，通过 `NODE_PATH` 指定 Playwright 所在的包目录。然后从项目根目录执行：

```powershell
node backend/scripts/verify-company-search.cjs
```

默认使用端口 8082、5176，也可设置 `VERIFY_BACKEND_PORT`、`VERIFY_FRONTEND_PORT`。脚本创建带时间戳的 `careernova_search_verify_...` 独立数据库，导入基础与演示数据并添加验证样例；结束后关闭临时服务并清理该数据库。开发数据库及已有服务不受影响。

脚本覆盖公司名及技能搜索、多条件交集、分页稳定性、禁用/删除可见性、公开字段、岗位数、非法参数及类似 SQL 的输入，以及首页切换、企业详情、刷新/返回恢复、筛选重置页码、失败重试、无结果状态和 1440/1024/768/375 宽度的布局。机器报告、日志和截图保存在忽略提交的 `backend/target/company-search-*`。

2026-10-16 验证结果：后端 39 个测试全部通过（0 失败、0 错误、0 跳过）；前端类型检查与生产构建通过；端到端 13 组检查全部通过，已检查桌面及手机截图，临时数据库与测试服务均已清理。本机系统 Node 曾在 Vite 构建产物生成后发生退出异常，改用内置 Node 24.19.0 后完整构建成功。Vite 仍提示现有公共依赖包体积超过建议阈值，不影响构建和本功能运行。

本地已有后端服务需要重启以加载新接口；前端开发服务刷新后即可加载页面变更。
